GRAPHIUM KEYBOARD SHORTCUTS — G06
=================================

File
  Ctrl+N          New
  Ctrl+O          Open…
  Ctrl+S          Save
  Ctrl+Shift+S    Save As…
  Ctrl+Q          Quit

Edit
  Ctrl+Z          Undo
  Ctrl+Shift+Z    Redo
  Ctrl+X          Cut
  Ctrl+C          Copy
  Ctrl+V          Paste
  Delete          Delete selection
  Ctrl+A          Select All

Search
  Ctrl+F          Find…
  F3              Find Next
  Shift+F3        Find Previous
  Ctrl+H          Replace…
  Ctrl+G          Go to Line…

Find Next/Previous are product commands, not private buttons in the search bar. After a
query has been entered, F3 and Shift+F3 continue to work when the search bar is hidden.
Search wraps once automatically.


View
  Ctrl++          Zoom In
  Ctrl+-          Zoom Out
  Ctrl+0          Reset Zoom
  F11             Full Screen

Status Bar, Line Numbers, Word Wrap and Font… are direct View commands without dedicated
accelerators in G06. Their persistent state is changed from the View menu rather than
duplicated in Preferences.

Help commands intentionally have no global accelerator in G06.

Linux Mint/Cinnamon note
------------------------
Graphium does not use Ctrl+Alt+L. New accelerators are checked against active desktop
global bindings before a desktop candidate is accepted.
