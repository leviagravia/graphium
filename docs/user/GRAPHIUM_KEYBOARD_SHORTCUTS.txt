GRAPHIUM KEYBOARD SHORTCUTS — G08
=================================

File
  Ctrl+N          New
  Ctrl+O          Open…
  Ctrl+S          Save
  Ctrl+Shift+S    Save As…
  Ctrl+Shift+P    Print Preview
  Ctrl+P          Print…
  Ctrl+Q          Quit

Edit
  Ctrl+Z          Undo
  Ctrl+Shift+Z    Redo
  Ctrl+X          Cut
  Ctrl+C          Copy
  Ctrl+V          Paste
  Delete          Delete selection
  Ctrl+A          Select All

Search
  Ctrl+F          Find…
  F3              Find Next
  Shift+F3        Find Previous
  Ctrl+H          Replace…
  Ctrl+G          Go to Line…

Find Next/Previous are product commands, not private buttons in the search bar. After a
query has been entered, F3 and Shift+F3 continue to work when the search bar is hidden.
Search wraps once automatically.


View
  Ctrl++          Zoom In
  Ctrl+-          Zoom Out
  Ctrl+0          Reset Zoom
  F11             Full Screen

Status Bar, Line Numbers, Word Wrap and Font… are direct View commands without dedicated
accelerators in G08. Their persistent state is changed from the View menu rather than
duplicated in Preferences.

Document
  Statistics… has no dedicated accelerator in G08.

G08 commands without dedicated accelerators
--------------------------------------------
Open Recent, Clear Recent, Save a Copy…, Save Version Copy…, Properties…, Page Setup… and
Statistics… are intentionally menu-driven. G08 adds only Ctrl+Shift+P for Print Preview and Ctrl+P
for Print.

Help commands intentionally have no global accelerator in G08.

Linux Mint/Cinnamon note
------------------------
Graphium does not use Ctrl+Alt+L. New accelerators are checked against active desktop
global bindings before a desktop candidate is accepted.

G09 text transformations
  Alt+Up    Move Lines Up
  Alt+Down  Move Lines Down
  Uppercase, Lowercase, Duplicate Line / Selection and Trim Trailing Spaces have no dedicated
  accelerator and remain explicit Edit -> Transform Text menu actions.
